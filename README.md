# Quotation Archive

A single-file web app for keeping supplier quotation PDFs, sorted by category and subcategory (Roof, Exterior joinery, ...).

## Use it
Open `index.html` in Chrome or Edge. No install or server needed.

- Right-click a category: add subcategory, rename, delete.
- Add quotes with a PDF, supplier, project, amount, date, notes and keywords; search finds all of them.
- "Choose save folder" saves PDFs and an index file in a folder you pick (Chrome/Edge only). Otherwise data stays in the browser.

## Online
Turn on GitHub Pages (Settings > Pages > Deploy from branch > main / root) to open it from any device.
Note: data is stored per browser/device, so use a save folder for a reliable copy.

## Change it
Edit `index.html` (HTML, CSS and JS in one file) and commit.
